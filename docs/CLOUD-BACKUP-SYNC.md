# UltraRig Cloud Backup & Multi-Pedal Synchronization Guide

Touring musicians, professional session players, and church guitarists frequently rely on multiple pedals: a **Primary Unit** mounted to the live pedalboard and a **Backup Unit** stored in the gig bag for disaster recovery. Others maintain a home studio pedal permanently connected to a DAW and a gig pedal that travels to rehearsals.

Synchronizing presets, NAM models, and cabinet IRs between multiple units ensures consistent sound across all rigs. However, confusing **low-level hardware backups** with **high-level preset libraries** can permanently brick a spare pedal.

This guide details safe cloud synchronization strategies (Google Drive, Dropbox, OneDrive, iCloud, GitHub), folder structures, directory junctions, and a 60-second stage disaster recovery procedure.

---

## 1. The Golden Safety Rule: Hardware Dumps vs. Preset Libraries

```
  ┌────────────────────────────────────────────────────────────────────────┐
  │         LOW-LEVEL HARDWARE FLASH DUMP (DANGER: CHIP SPECIFIC)          │
  │  Location: Documents\tankg_installer\backup_<date>                     │
  │  Contains: MCU serial IDs, factory ADC/DAC calibration tables, BT MAC  │
  │  RULE: NEVER flash Unit A's hardware dump onto Unit B!                 │
  │  RESULT OF VIOLATION: Unit B bricked or permanent calibration loss.    │
  └────────────────────────────────────────────────────────────────────────┘

  ┌────────────────────────────────────────────────────────────────────────┐
  │        HIGH-LEVEL PRESET & ASSET LIBRARIES (100% PORTABLE)             │
  │  Formats:  .json (Presets/Scenes), .nam (A2-Lite Models), .wav (IRs)   │
  │  Contains: Musical signal flow, knob parameters, and impulse files     │
  │  RULE: 100% safe to sync, share, and clone across ANY pedal!           │
  │  COMPATIBILITY: Tank-G v1, Tank-G v2, Tank-B, Black Box               │
  └────────────────────────────────────────────────────────────────────────┘
```

> [!CAUTION]
> Hardware flash dumps generated by `UltraRig-Installer.exe` are tied to the physical silicon of that specific pedal. Keep them strictly quarantined in device-specific folders. Only synchronize your **`.json` preset files, `.nam` captures, and `.wav` IRs** across pedals.

## 2. Canonical Cloud Storage Directory Structure

Create a master synchronized folder inside your preferred cloud provider (Google Drive, Dropbox, OneDrive, iCloud, or a private Git repository):

```
 UltraRig-Cloud/
 ├── Presets/

 │   ├── Bank_01_Clean_Acoustic.json

     ├── Unit_1_Main_Pedalboard_Serial_ABC/
     └── Unit_2_Spare_GigBag_Serial_XYZ/
```

## 3. Automating Local Sync via Directory Junctions (Symlinks)

To prevent manual file copying every time you export a preset from the UltraRig Web Editor, link your local documents directory directly to your cloud storage folder.

### On Windows 10 & 11 (Command Prompt as Administrator):
```cmd
mklink /J "%USERPROFILE%\Documents\UltraRig-Presets" "%USERPROFILE%\OneDrive\UltraRig-Cloud\Presets"
```

### On macOS / Linux (Terminal):
```bash
ln -s ~/Dropbox/UltraRig-Cloud/Presets ~/Documents/UltraRig-Presets
```

Now, whenever you export a preset or library from the UltraRig Editor into `Documents\UltraRig-Presets`, your cloud client immediately uploads the file, making it accessible on your laptop, studio desktop, or mobile tablet.

## 4. The 60-Second Stage Disaster Recovery Procedure

If your primary pedalboard unit suffers a sudden hardware failure (liquid spill, power surge, broken footswitch) minutes before showtime:

```
 [ Step 1: Unbox Spare Unit ]
             │
             ▼
 [ Step 2: Connect USB Cable to Laptop or Phone ]
             │
             ▼
 [ Step 3: Open UltraRig Web Editor (Chrome/Edge) ──> Click Connect ]
             │
             ▼
 [ Step 4: Library Manager ──> "Import Master Library" ]
             │
             ▼
 [ Step 5: Select "Setlist_2026_Tour.json" from Cloud Folder ]
             │
             ▼
 [ 100% Stage-Ready Tone Cloned in Under 60 Seconds ]
```

1. **Unbox the Spare Pedal:** Retrieve your backup Tank-G/Tank-B from your gig bag and connect it to power.
2. **Connect to Editor:** Plug the USB cable into your laptop, iPad, or Android phone and open the UltraRig Editor.
3. **Import Master Library:** Navigate to **Settings** → **Backup & Library** → click **Restore Preset Library**.
4. **Select Cloud Backup:** Pick your latest `Setlist_2026_Tour.json` file.
5. **Verify NAM & IR Slots:** Ensure the backup unit contains the corresponding custom NAM captures and IR files in its flash memory slots.
6. The spare pedal now mirrors your main pedalboard rig with 1:1 parity.

## 5. Version Control for Touring Musicians (Git Workflow)

Treating presets as code using a private GitHub or GitLab repository provides unprecedented reliability on the road:

```bash
# Example Git commit log during a multi-city tour
git commit -m "Tour Date 03: Raised master Low Cut to 95 Hz for boomy arena soundcheck"
git commit -m "Tour Date 05: Added +2 dB clean boost to Scene C on Song 4"
git commit -m "Tour Date 08: Swapped IR Slot 3 for darker ribbon mic impulse"
```

* **Instant Rollbacks:** If an experiment during rehearsal made your presets sound worse, roll back to yesterday's commit with a single command.
* **Tour Audit Trail:** Every EQ tweak, drive parameter change, and scene reconfiguration is timestamped and documented.

## 6. Multi-Pedal Synchronization Checklist

- [ ] Low-level hardware backups strictly segregated into separate device folders.
- [ ] Master library `.json` saved and synced to cloud storage (Google Drive/Dropbox/OneDrive/Git).
- [ ] Custom `.nam` models and 1024-point `.wav` IRs pre-loaded into the exact same memory slots on both pedals.
- [ ] Directory junction created between local docs and cloud storage.
- [ ] Spare unit tested and verified before leaving for tour.
- [ ] Cloud sync client configured for offline availability on your stage laptop/tablet.
